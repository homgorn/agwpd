❓ Часто задаваемые вопросы

Как Antigravity помогает с Notion API Sync? ▼
Antigravity берет на себя рутину: от скаффолдинга проекта до написания конкретной логики Notion API Sync, позволяя вам сосредоточиться на архитектуре.
Нужно ли мне знать синтаксис языка досконально? ▼
Для задачи Notion API Sync глубокое знание не обязательно, так как агент генерирует синтаксически верный код, но понимание логики поможет при ревью.
Может ли агент исправить ошибки в Notion API Sync? ▼
Да, Antigravity имеет цикл обратной связи: он читает ошибки из терминала и автоматически предлагает исправления.
Как интегрировать это в существующий проект? ▼
Агент умеет работать с контекстом. Просто откройте ваш проект и попросите добавить функционал Notion API Sync в существующую структуру.
Какие модели используются? ▼
По умолчанию Gemini 3, но вы можете переключиться на Claude Sonnet или GPT-OSS в настройках агента.
Безопасно ли доверять агенту Notion API Sync? ▼
Код выполняется в песочнице, и вы всегда должны подтверждать критические действия (удаление файлов, API запросы).
Сколько времени занимает генерация? ▼
Простые задачи типа Notion API Sync решаются за 1-3 минуты. Сложные архитектурные изменения могут занять до 10-15 минут.
Генерируются ли тесты? ▼
Да, мы рекомендуем всегда просить агента генерировать тесты для Notion API Sync для гарантии качества.
Можно ли экспортировать результат? ▼
Конечно, результат — это обычные файлы в вашей файловой системе, которые можно залить в Git.
Поддерживается ли командная работа? ▼
Да, через Manager Surface вы можете видеть, над чем работают агенты ваших коллег в реальном времени.
Нужен ли доступ в интернет? ▼
Для работы модели нужен интернет, но локальный код остается на вашей машине (если не включена облачная синхронизация).
Как улучшить качество генерации для Notion API Sync? ▼
Чем детальнее ваш промпт и контекст (открытые файлы), тем лучше результат. Используйте @-упоминания файлов.
Есть ли плагины для Notion API Sync? ▼
Antigravity поддерживает расширения VS Code, поэтому вы можете использовать привычные инструменты.
Что делать, если агент завис? ▼
Вы можете перезапустить задачу или уточнить промпт. Состояние агента сохраняется.
Где найти документацию? ▼
Вся документация доступна на официальном сайте antigravity.google и в этом справочнике.
