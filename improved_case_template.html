📝 Готовый промпт для копирования

Скопируйте этот промпт и вставьте в Antigravity для мгновенного старта:

Создай React компонент UserCard для отображения информации о пользователе.

Требования:
- TypeScript с строгой типизацией
- Пропсы: name (string), avatar (string), role (string), isOnline (boolean)
- Styled Components для стилей
- Адаптивная верстка (мобильная и десктоп)
- Анимация появления (fade-in)
- Индикатор онлайн статуса (зеленая точка)
- Кнопка "Send Message" с обработчиком onClick
- Unit-тесты с React Testing Library
- Storybook story с разными вариантами
💡 Совет: Чем детальнее промпт, тем лучше результат. Укажите библиотеки стилей, требования к доступности и edge cases.

📖 Пошаговая инструкция

Откройте проект в Antigravity

Убедитесь, что в корне есть package.json с React зависимостями. Antigravity автоматически определит версию и настроит генерацию.

Выберите модель Gemini 3 Pro (High)

Для сложных компонентов с TypeScript рекомендуется максимальная точность. Для простых UI элементов можно использовать Gemini 3 Fast.

Вставьте промпт в чат

Используйте готовый промпт выше или адаптируйте под свои нужды. Укажите конкретные библиотеки и паттерны вашего проекта.

Дождитесь создания Implementation Plan

Агент проанализирует запрос и покажет план действий. Вы можете добавить комментарии или уточнения перед выполнением.

Наблюдайте за генерацией в реальном времени

Код появится построчно в редакторе. В терминале отобразятся команды установки зависимостей (если нужны).

import React from 'react';
import { Container, Avatar, Name, Role, OnlineIndicator } from './UserCard.styles';

interface UserCardProps {
  name: string;
  avatar: string;
  role: string;
  isOnline: boolean;
  onMessageClick?: () => void;
}

export const UserCard: React.FC<UserCardProps> = ({
  name,
  avatar,
  role,
  isOnline,
  onMessageClick
}) => {
  return (
    <Container>
      <Avatar src={avatar} alt={name} />
      {isOnline && <OnlineIndicator />}
      <Name>{name}</Name>
      <Role>{role}</Role>
      <button onClick={onMessageClick}>Send Message</button>
    </Container>
  );
};

❓ Часто задаваемые вопросы

Может ли Antigravity работать с существующим проектом? ▼
Да, Antigravity отлично работает с существующими проектами. Он анализирует вашу кодовую базу и генерирует компоненты в том же стиле.
Как Antigravity обрабатывает TypeScript? ▼
Если в проекте есть tsconfig.json, Antigravity автоматически генерирует код с типизацией, создает интерфейсы для пропсов и типизирует хуки.
